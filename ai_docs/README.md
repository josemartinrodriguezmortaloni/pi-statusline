# Pi documentation snapshot

Local reference for building pi-statusline.

- Source: `@earendil-works/pi-coding-agent` v1.0.1, the version pinned in `package.json`, plus the READMEs of `pi-ai`, `pi-agent-core` and `pi-tui` from the same install.
- `pi-<page>.md`: every page of the coding-agent `docs/` directory, unchanged.
- `pi-coding-agent.md`: the coding-agent README. `pi-tui-library.md`: the pi-tui README.
- `example-extension-*.md`: the extension examples that cover footers, statuses, commands, tools and `sendUserMessage`.
- Regenerate after a pi upgrade by copying the same files from `node_modules/@earendil-works/`.

Read first: [extensions](pi-extensions.md), [TUI](pi-tui.md), [themes](pi-themes.md), [settings](pi-settings.md), [custom footer example](example-extension-custom-footer.md).
